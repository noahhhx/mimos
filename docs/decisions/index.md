# Decisions

Architecture decision records (ADRs). Each records a decision that a future
contributor could plausibly make differently, with the context that made it
right at the time.

| ADR                                                                 | Decision                  |
| ------------------------------------------------------------------- | ------------------------- |
| [ADR-0001](adr-0001-backend-module-layout.md)                       | Backend module layout     |

New ADRs are sequential: `adr-NNNN-title.md`, with the numbering in this
index. Once accepted, an ADR is never rewritten — superseding decisions get
their own ADR that links back.
